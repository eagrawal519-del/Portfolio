## 4. Recommended Architecture

### Framework Recommendation: **Modern Vanilla Architecture (HTML5 + Modular CSS + Modern ES6 JS) with Zero External Dependencies**

**Rationale**:
* **100 Lighthouse Score**: Zero JavaScript runtime overhead, instant sub-second First Contentful Paint (FCP) and Largest Contentful Paint (LCP).
* **Zero Dependency Fragility**: No broken `node_modules`, no npm security vulnerabilities, zero build step required to preview or host.
* **Universal Deployment**: Runs natively on GitHub Pages, Vercel, Netlify, Cloudflare Pages, or static Python/Node server directly out of `https://github.com/eagrawal519-del/Portfolio`.
* **Crisp Custom SVG Graphics**: Handcrafted, scalable, animated SVG gadgets (Anywhere Door, 4D Pocket, Take-Copter, Time Machine, Bell Crest) that render pin-sharp at any screen density without external image requests.
* **Full Accessibility & Motion Control**: Semantic HTML5 elements, native keyboard tab stops, ARIA live regions, and strictly respected `prefers-reduced-motion`.
