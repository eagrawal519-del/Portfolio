## 🛠️ Tech Stack & Architecture

* **Markup**: Semantic HTML5 with complete ARIA landmarks and Schema.org JSON-LD structured data.
* **Styling**: Modular CSS3 with custom properties (design tokens), clamp-based fluid typography, and multi-breakpoint responsive styling.
* **Motion & Interactions**: Vanilla ES6 JavaScript utilizing `IntersectionObserver` for staggered scroll reveals, scroll tracking, and accessible mobile controls.
* **Assets**: 100% original scalable vector graphics (SVG) crafted specifically for this project (no pixelated rasters, no copyrighted brand art).
* **Zero Runtime Dependencies**: No npm packages, no bundle bloat, instant sub-second loading, and native support for GitHub Pages, Vercel, Netlify, and Cloudflare Pages.

## 🚀 Running Locally

Because the project requires no external build tools or bundlers, you can preview it immediately using any local web server:

### Option 1: Python HTTP Server (Built-in)
```bash
python -m http.server 8080
```
Then open `http://localhost:8080` in your web browser.

### Option 2: Node / npx serve
```bash
npx serve .
```

### Option 3: VS Code Live Server
Right-click `index.html` and select **"Open with Live Server"**.
